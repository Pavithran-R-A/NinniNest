# Premium UI art direction / acceptance contract

Design thesis: **Quiet Observatory**—contemporary editorial care journal, serene in daylight, beautiful at night. It should look designed by a human product team for genuine 3am use, not generated by adding gradients and glass boxes.

## Screen composition
- Welcome: 1 expressive abstract line motif (crescent/ribbon), concise honest privacy statement, large action "Begin without an account". No random stock infant photos.
- Profile: friendly and emotionally respectful, only nickname/date of birth; optional prematurity details later and only with credible medical guidance.
- Today: use an airy header, a compact care-status band, low-drag action dock, activity stream visible without scrolling much; timer treatment is elegant and prominent. Keep one live timer accessible while sheet is open.
- Quick log: bottom sheet, keyboard never obscures actions. Diaper in 1 tap, bottle amount/milk type, breastfeeding left/right timer, sleep start/stop, pumping duration/quantity. Undo toast. Every save persists.
- Journal: timeline spine/ribbon aligned to events, clearly encoded by shape + label, never colors alone; date jump/edit/delete accessible.
- Handoff: polished letter-like surface showing recorded feed, sleep and diaper plus notes for a selected 12h/24h window. Copy/share in two taps; use actual data and mark not recorded.
- Insights: restrained mini-visuals with numbers and accessible textual equivalents. Never advise a parent a baby is medically abnormal because of missing logs.
- Growing: modules for solids, growth, milestones, meds/vax records, tummy time; emphasize family trust over gamification.
- Settings: beautiful typography, plain-language data ownership and export/import/erase controls, language/theme/preferences and a real help page.

## Exact visual standards
- 8pt spacing rhythm, minimum body 15–16sp, headlines 24–34sp, tap zones >=48dp for primary actions.
- Two design families only: day and midnight. Both must work with OS accessibility large text.
- Distinctive touch: quiet animated timer ring; "recorded" confirmation trace; care ribbon timeline; printed-like handoff. Keep animation optional for reduced motion.
- Avoid: gradient blob backgrounds, identical four-by-four cards everywhere, floating emoji, generic blue/purple gradient, centered SaaS hero, tiny illegible labels, medical red alert by default.
- Self-audit on 360x800 Android, 390x844 iPhone preview, 768px tablet and 1440px web. On mobile, ensure keyboard/tap/scroll interactions are functional.
- Accessibility acceptance: contrast 4.5:1 body; adjustable type; TalkBack/VoiceOver labels; semantic heading order on web; haptics optional; icon labels.
- Performance goals to measure, not assert: cold start under 3 seconds on a mid-range Android device; log core care event with <=3 taps; no dropped input; timer remains correct on restart; 60 FPS on simple navigation.

## Distinctiveness test
If all text/logos/colors were removed and the screen resembled any default Expo template or copied competitor, redesign it. Demonstrate strong editorial hierarchy, care ribbon, typography contrast, calm animation, and real workflow efficiency instead of excessive surface decoration.
